# Блэкджек

Браузерная игра в блэкджек на чистом HTML, CSS и JavaScript. Без зависимостей и сборки, работает на компьютере и телефоне.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка: вкладки «Игра», «Руда», «Магазин» |
| `style.css` | стили, адаптивная вёрстка, темы карточек |
| `db.js` | сохранение в `localStorage` с защитой от накрутки |
| `script.js` | логика блэкджека |
| `mine.js` | 3D-кликер добычи руды |
| `shop.js` | магазин фонов и карточек |
| `backgrounds.js` | анимированные фоны, нарисованные кодом |
| `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png` | установка на главный экран |

Файл `minigame.js` из прошлой версии больше не нужен — удалите его из репозитория. Загружайте все файлы сразу: при несовпадении версий игра покажет ошибку. У файлов в `index.html` стоит `?v=3`; при следующих правках увеличивайте номер.

## Блэкджек

- Стартовый банк 1000 ₽, блэкджек платит 3:2, дилер добирает до 17, ничья возвращает ставку.
- **Дабл** — только на первых двух картах: ставка удваивается, вы берёте одну карту.
- Закрытие страницы посреди раунда = проигрыш ставки.
- «Начать заново» доступно только при пустом банке.

## Защита от накрутки

- Сохранение подписано SHA-256: ручная правка в DevTools сбрасывает прогресс.
- Подмена сохранения старой копией во время игры тоже обнаруживается.
- Из консоли нельзя начислить деньги: денежные функции доступны только модулям игры.
- Выплату в блэкджеке и награду за руду считает `db.js`, а не интерфейс.
- Кликер принимает только настоящие нажатия (не `click()` из кода), не чаще 12 в секунду; слишком ровный ритм (автокликер) даёт паузу 5 секунд.

Это защита от лёгкой накрутки. Всё работает в браузере игрока, поэтому опытный человек, изучивший исходный код, обойти её может. Полная защита возможна только с сервером.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Branch: `main`.
