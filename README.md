# Блэкджек

Простая браузерная игра в блэкджек на чистом HTML, CSS и JavaScript. Без зависимостей и сборки.

## Структура

- `index.html` — разметка страницы
- `style.css` — стили
- `script.js` — логика игры
- `README.md` — описание

## Запуск

Откройте `index.html` в любом современном браузере. Ничего устанавливать не нужно.

## Правила

- Стартовый банк: 1000 ₽.
- Цель — набрать больше очков, чем дилер, но не более 21.
- Туз считается как 11 или 1 в зависимости от ситуации.
- Блэкджек (туз + картинка или 10 с первых двух картах) оплачивается 3:2.
- Дилер добирает карты, пока у него меньше 17 очков.
- При ничьей ставка возвращается.
- Когда банк пуст, игра предлагает начать заново.

## Управление

- **Раздать** — начать раунд с указанной ставкой.
- **Ещё** — взять карту.
- **Стоп** — остановиться и передать ход дилеру.
- Клавиша **Enter** в поле ставки тоже запускает раздачу.
